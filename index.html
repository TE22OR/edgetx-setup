SET UP YOUR RADIOIN ONE GO

⚡ No SD card removal

Plug your radio in, pick a few options, and this writes a ready-to-fly drone model, voice call-outs, stick logging and a sim model straight onto it. Everything is backed up first.

  1. Connect
  2. Choose
  3. Apply

1. Connect your radio

  1. Switch the radio on as normal.
  2. Plug a USB-C data cable into the top port of the Pocket and into your computer.
  3. The radio asks Select mode. Scroll to USB Storage (SD) and press the wheel. Only this mode works here.
  4. A new drive appears on your computer. Click Connect radio and pick that drive (it has RADIO and MODELS folders inside).

  • No Select mode menu? Your radio is set to pick a mode on its own. Unplug, then press SYS, PAGE> to RADIO SETUP, find USB mode and set it to Ask. Plug back in.
  • Radio charges but no drive appears? The cable is charge-only. Try another USB-C cable, and check you used the top port.
  • Drive appears but Connect says it's wrong? You picked a folder inside it. Pick the drive itself.
  • Finished? Eject the drive on your computer before unplugging, so nothing is half-written.

Which browsers?
Writing straight to the radio needs Chrome or Edge on Windows, Mac or Linux. Firefox and Safari can read the radio and give you a zip to copy across instead. Files are checked against EdgeTX 2.12's own file reader, and 2.10–2.11 use the same format. Built for the RadioMaster Pocket. Other black-and-white EdgeTX radios should work but are untested.

⚙️
Wheel source name
In EdgeTX mixer: System → Inputs, check what your scroll wheel appears as. Common values: ENC1, SC, 6POS. Update in the Radio tab → Scroll Wheel → Source. The script uses ENC1.
⚠️
MSP payload verification needed
MSP_SET_RC_TUNING (cmd 204) byte order for ACTUAL rates type should be verified on your BETAFPVG473_V2 / BF 2026.6.0-alpha. The structure used here follows standard BF MSP docs: rcRate, expo, superRate (roll/pitch), superRate (yaw), … yawExpo, rollExpo, pitchRcRate, pitchExpo. Enable Betaflight MSP logging or test with small values first.
📡
EdgeTX function script setup
In EdgeTX: Special Functions → Add → switch always-on → Function: Lua → Script: rtblend → enable. The script runs in the background and sends rate updates via CRSF MSP every ~150ms when the wheel moves. ELRS must have MSP enabled in ELRS Lua configurator.

Needs EdgeTX 2.9 or newer
The Enabled Features menu arrived in EdgeTX 2.9. Check yours under SYS → PAGE> to VERSION. Telemetry script names are limited to 6 characters, which is why it's mdrec. Hiding most menus only hides the page and deletes nothing. Special Functions and Global Functions are different: hiding them also stops them running, so this tool keeps them on when your logging or rate blend needs them.
